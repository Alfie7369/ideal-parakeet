Coursework & Analysis

Real Analysis

An exploration of limits and continuity. The formal (\( \epsilon, \delta \)) definition of a limit states that for a function \( f(x) \), \( \lim_{x \to c} f(x) = L \) if and only if:

$$ \forall \epsilon > 0, \exists \delta > 0 \text{ such that } 0 < |x - c| < \delta \implies |f(x) - L| < \epsilon $$

This rigor forms the foundation of advanced continuous models.

Statistical Modeling

Analysis of variance and linear regression models. The standard multiple linear regression model is defined as:

$$ Y_i = \beta_0 + \beta_1 X_{i1} + \dots + \beta_p X_{ip} + \epsilon_i $$

Where the error term is assumed to be normally distributed with a mean of zero and constant variance: \( \epsilon_i \sim N(0, \sigma^2) \).
